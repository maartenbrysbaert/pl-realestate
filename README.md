# PL Real Estate

Angular rebuild of `pl-realestate.com`, replacing the Squarespace 7.1 site. Static,
trilingual, deployed to Netlify.

```
app/          Angular 22 application
tools/        one-off migration + fidelity tooling (not part of the app build)
netlify.toml  build, redirects, headers
```

Two paths are local-only and gitignored: `reference/` holds the captured Squarespace
originals and side-by-side comparisons, regenerated by `tools/capture-reference.mjs`;
`NOTES.md` holds working notes and open items. The app builds without either.

## Quick start

```bash
cd app
npm install
npm start                 # Dutch, http://localhost:4200
npm run start:fr          # French
npm run start:en          # English
npm run build             # all three locales + sitemap + link check
```

`npm run build` fails the build if any Squarespace or Typekit reference survives into
the output.

## Architecture

**Locales.** Build-time `@angular/localize`. Three prerendered static builds from one
source, configured in `angular.json`:

| Locale | URL prefix | Output |
| --- | --- | --- |
| `nl-BE` (source) | none | `dist/app/browser/` |
| `fr-BE` | `/fr` | `dist/app/browser/fr/` |
| `en-GB` | `/en` | `dist/app/browser/en/` |

Dutch stays at its original paths (`/over`, `/diensten`, …) so existing search rankings
and inbound links are untouched. Route slugs are deliberately **not** translated —
`/fr/over`, not `/fr/a-propos`.

Because each locale is a separate build, the language switcher uses plain `<a href>`
rather than `routerLink`. It is always present in the DOM and hidden with CSS, so the
sibling-locale URLs appear in the prerendered HTML.

**Rendering.** `outputMode: "static"` — every route is prerendered to its own HTML file
at build time. 21 files (6 pages + a 404, × 3 locales). There is no server at runtime,
no SSR functions and no cold starts; Netlify's Angular runtime plugin auto-installs but
has nothing to wire up without a server bundle. `tools/generate-sitemap.mjs` **fails the
build** if a `server/` bundle ever reappears, so this cannot regress silently.

Do not add a catch-all SPA rewrite to `netlify.toml`; it would turn real 404s into 200s.

**Images.** The slideshow mounts only a three-slide window (previous / current / next) —
all slides are stacked in the viewport, so `loading="lazy"` defers nothing and the
homepage otherwise pulled all 43 photos. The `/referenties` grid uses a plain `<img>`
rather than `NgOptimizedImage`: Angular unconditionally prepends `auto` to `sizes` on
lazy images, and Chrome's preload scanner resolves `sizes: auto` as 100vw before layout,
fetching every tile twice. Both are load-bearing — see the comments in
`project-gallery.ts` before changing either.

**Translations.** Do not hand-edit the XLIFF files.

```bash
cd app && npx ng extract-i18n     # regenerate messages.xlf from the source
node ../tools/build-translations.mjs
```

Translations live in `tools/translations.mjs`, keyed by the Dutch source string. Any
string without a translation is reported and passed through as Dutch, and the script
exits non-zero.

**Styling.** Tokens in `app/src/styles/_tokens.scss` were lifted from the original's
*computed* styles, not its class names — `capture-reference.mjs` + `extract-tokens.mjs`
regenerate that evidence into `reference/squarespace/extracted/`. The
fractional sizes (`26.368px`, `47.104px`) are Squarespace's fluid scale, kept verbatim
because rounding them changes where the Dutch copy wraps.

Two tokens deliberately depart from the original. `--font-heading` is Archivo, a freely
licensed neo-grotesque standing in for the original's Acumin Pro; body (Poppins) and
wordmark (Rajdhani) are unchanged. `--c-stone` is `#6f6c69` rather than `#a3a09e`, which
scored 2.59:1 on white — under the WCAG AA floor both as text and as a button fill
behind white labels.

**Contact form.** Netlify Forms. `app/public/__forms.html` is a hidden static form that
exists purely so Netlify's build-time HTML scan registers it; the Angular component
POSTs to it as URL-encoded form data with a `form-name` field. Notification recipients
are configured in the Netlify UI, not in this repo.

Two deploy-time gotchas, both of which look like "the form silently does nothing":

- **Form detection is opt-in per site** (Project configuration → Forms). It is enabled
  on `pl-realestate`, but a site deployed *before* it was switched on has no registered
  form — detection is not retroactive, so the next deploy after enabling it is what
  actually registers `contact`.
- **Every field the app submits must exist in `__forms.html`.** Netlify drops anything
  it did not see at build time, without erroring. Add a field to the Angular form and
  you must add it there too.

## Tooling

Run from `tools/` after `npm install` there.

| Script | Purpose |
| --- | --- |
| `capture-reference.mjs` | Screenshots + HTML + computed styles. `--base` to point at the rebuild, `--out` to name the output set |
| `extract-content.mjs` | Pulls collapsed accordion bodies and gallery captions out of captured HTML |
| `extract-tokens.mjs` | Per-element computed typography, keyed by text |
| `process-images.mjs` | Downloads CDN originals, emits responsive WebP, regenerates `app/src/app/data/projects.ts` |
| `build-translations.mjs` | messages.xlf + translations.mjs → per-locale XLIFF |
| `generate-sitemap.mjs` | sitemap.xml, robots.txt, 404.html, Squarespace-reference check |
| `measure-diff.mjs` | Numeric landmark comparison, original vs rebuild |
| `compare.mjs` | Side-by-side screenshot stitching |

Open items, sign-offs and the cutover plan live in `NOTES.md` (local only).

## Quality gates

Lighthouse on the production build, desktop preset, all six Dutch pages:

| | performance | accessibility | best practices | SEO |
| --- | --- | --- | --- | --- |
| all pages | 99–100 | 100 | 100 | 100 |

Regression sweep over 54 combinations (6 pages × 3 locales × 3 breakpoints): zero
console errors, zero failed requests, zero horizontal overflow, zero broken
language-switcher links.

No third-party requests at runtime: fonts, images, scripts and styles are all
self-hosted, which is what lets `netlify.toml` keep a strict CSP and the site set no
cookies.
